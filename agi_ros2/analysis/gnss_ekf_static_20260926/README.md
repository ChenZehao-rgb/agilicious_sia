# 普通 GNSS 漂移、EKF 校正台阶与其他问题

本次只分析用户指定的 `bags/hardware_20260926_161859_702449`。
优先顺序是：传感器与输入质量检查（特别是 IMU 加速度标定）→噪声离散化及拒收恢复逻辑→EKF 数值调参。
普通 GNSS 的时变漂移不能靠重设原点、减去一个常数，或校准磁力计来消除。

## 小跳变与GNSS校正一一对应

用同一初始化/reset段内rtk_stamp推进识别导航接受，前100秒共有912次。
该段reset_counter恒2、导航拒收恒0；更新NIS最大7.954。

为排除两帧间正常传播，定义近似校正量：

```text
delta_p_proxy = p[k] - p[k-1] - v[k-1]*dt - 0.5*a[k-1]*dt^2
```

这是输出时刻的校正代理量，包含迟到观测校正后的再传播影响，不是滤波器内部精确Kalman增量。

| 导航更新帧校正量 | 中位数 | P95 | 最大 |
|---|---:|---:|---:|
| 水平模 | 1.217 cm | 3.515 cm | 4.340 cm |
| 垂直绝对值 | 1.585 cm | 4.899 cm | 5.230 cm |
| 三维模 | 2.035 cm | 5.867 cm | 6.184 cm |

非导航更新帧同一算法的三维残差P95约1.0微米，说明厘米级台阶与导航校正相符，不是时间戳重复或重置。
60–100秒台阶比早段更明显，与位置/速度/惯性预测不一致的累积同时出现。
GNSS在有效采样时间处校正，随后推进到最新IMU时间；前100秒被融合的导航时刻距当前输出时刻中位46.6 ms、P95 98.0 ms。
这些是已发布采样时间间隔，不能直接解释成原始GNSS解算硬件延迟。

## IMU标定与时序

前100秒49921条IMU平均加速度为[-0.26268, 0.17663, 9.44405] m/s²；平均向量模9.44935 m/s²。
相对项目g=9.8066低0.35725 m/s²，约3.643%。32个完整3秒窗口的模长偏差为-0.421至-0.310 m/s²。
加速度各轴标准差约[0.01356, 0.01288, 0.03346] m/s²；噪声不大但存在稳定偏差。

单姿态无法区分零偏、比例因子和其他来源，应先执行飞控规定的加速度计标定，再以多个静置朝向复测。
姿态倾斜不会改变理想重力向量的模长；FRD/FLU符号转换也不会改变模长。
不要用单个9.8066/9.44935比例直接缩放全部加速度，也不要把放宽gravity_tolerance当作标定。
EKF反推的ba_z在60–100秒平均约-0.359 m/s²，表明其正在补偿非零偏差；这是内部状态重建，不是传感器标定真值。

全程IMU采样499.376 Hz，最大采样间隔3.109 ms，无重复、倒退或>5 ms间隔。
因此后段EKF失败不是原始IMU断流。

## 当前源码的额外风险

1. `ekf_imu.cpp`在100微秒数值子步内以dt²累计IMU噪声和Q，使噪声注入量依赖人工积分子步。
   必须先明确参数是连续谱密度还是逐采样方差，并检验改变纯积分步长时协方差基本不变，再调参数。
   不可在单位不明确时机械放大20倍或10000倍；也不能据当前源码把它断言为本包漂移的唯一原因。
2. 100秒末后验位置标准差约[0.158,0.157,0.206] m，而静止位置已有米级变化。
   该协方差是模型内估计，不能作为实际误差保证。拒收时后验covariance_stamp冻结，不能当最新状态协方差。
3. 标准/state的pose/twist covariance未填写，默认全零；依赖其不确定度的外部消费者需要修正。
4. 全包estimator_ready/navigation_ready/accuracy_ok均false。精度准入未通过不等于没有GNSS融合；
   navigation_accepted_updates受精度门槛控制，全0不表示EKF未接受观测。
   readiness_reason可能被精度原因覆盖，需同时查看NIS、拒收计数、rtk_stamp和covariance_stamp。
5. 190.831秒有-105.9°航向步变，但该段同时快速转动且接近机头竖直，pitch约-84°。
   Euler yaw在这种姿态下可突变，不能据此判定磁力计故障。100秒后缺少动作真值，需单独动态复测。
6. 测量模型未补偿GNSS天线到IMU的杆臂。它不是前100秒静止慢漂移的解释，动态旋转试验需核对。

## 推荐实施顺序

1. 校准并复测IMU；同时在开阔静止条件检查GNSS天线朝向、安装、供电和干扰，记录卫星数、DOP、C/N0、温度、
   冷启动/稳定后重复结果。现有bag缺这些接收质量证据，不能唯一归因于多路径、天线或接收机。
2. 修正/明确噪声离散化与连续拒收恢复策略，补充每轴创新、协方差时刻和处理耗时诊断。
3. 用标定后的静止与独立动态日志设置R/Q：区分GNSS水平/垂直位置与速度噪声，考虑慢漂移相关性，
   检查NIS、偏置收敛、动态误差和拒收恢复。增大位置R可能减小台阶，也会减少绝对位置约束；不能以曲线最平为目标。
4. 确定传感器确实能达到的精度后再填写accuracy与covariance准入门限。
   若任务需要比实测普通GNSS更稳定的高度/位置，应评估独立高度/位置观测，而不是只靠调参。

GPS环境与天线检查依据：[GPS.gov GPS Accuracy](https://www.gps.gov/gps-accuracy)、
[u-blox GNSS antennas application note](https://content.u-blox.com/sites/default/files/products/documents/GNSS-Antennas_AppNote_%28UBX-15030289%29.pdf)。
这些资料支持一般影响因素，不证明本包发生了其中某一种故障。
